## Installation

**HACS → ⋮ → Custom repositories** → `stefgo/ha-legend-table`, category **Dashboard** →
*Add*, then install "Legend Table Cards". The bundle contains both
`custom:statistics-legend-table` and `custom:entity-legend-table`.

Manually: download `legend-table.js` from the assets below, copy it
to `config/www/community/ha-legend-table/` and register it as a
dashboard resource of type *JavaScript Module*.

Full documentation is in the [README](https://github.com/stefgo/ha-legend-table#readme).
